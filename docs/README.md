# Salary Management

A web app that lets an HR Manager manage salary data for ~10,000 employees across
multiple countries and answer "how does the org pay people?" without spreadsheets.

## Tech stack
- Backend: Java 21, Spring Boot 3, Spring Data JPA, Flyway
- Database: PostgreSQL
- Frontend: Angular, Angular Material
- Testing: JUnit 5, Mockito, Testcontainers
